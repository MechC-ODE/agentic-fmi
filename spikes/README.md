# Spikes

These scripts are feasibility spikes: time-boxed experiments that answer one question each about a library (FMPy, OMSimulator, pythonfmu) and record the evidence. They're throwaway evidence, not product code. Nothing in `src/` imports them, they have no tests, mypy doesn't check them, and they may break when a pinned library changes. Each script runs inside the dev container with `uv run python spikes/<name>.py`, prints a JSON report and writes it, plus any generated FMUs, SSPs or result files, to the gitignored `.cache/spikes/<letter>/`. The verdicts, measured numbers, verbatim errors and design implications are in [docs/spikes.md](../docs/spikes.md). To use a finding in product code, re-implement it properly under `src/` with tests. Don't copy a spike.
