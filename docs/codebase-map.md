# Codebase map

What each path is for and where to start reading. Keep this file current: every task that adds, moves or removes a file updates it.

## Exists now (through Phase 4)

> **Status:** every module listed below exists; none is a stub. Live runs and the pane are described in [ADR 0010](adr/0010-live-runs-and-the-pane.md), systems in [ADR 0009](adr/0009-systems-with-omsimulator.md).
